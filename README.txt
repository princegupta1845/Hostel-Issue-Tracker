HOSTEL ISSUE TRACKER
====================

A simple hostel complaint/maintenance tracking mini project.

Technology:
- HTML
- CSS
- JavaScript
- localStorage

Main features:
- Dashboard statistics
- Report hostel issues
- Search and filter issues
- Priority levels
- Issue status tracking
- Issue timeline
- My Issues
- Resolution notes
- Responsive layout

Pages:
index.html
report.html
issues.html
issue.html
my-issues.html

How to run:
Open index.html in a browser. No server or database is required.

Note:
The project stores data in the browser's localStorage. Demo issues are included for presentation/testing.
